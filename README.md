# Romantic Birthday Gift

This repository contains a Replit-exported pnpm workspace for a romantic interactive birthday website.

## Run locally

1. Install dependencies:

   ```bash
   pnpm install
   ```

2. Start the website:

   ```bash
   pnpm run dev
   ```

3. Open `http://localhost:5173`.

## .Useful commands

- `pnpm run dev` — run the website
- `pnpm run dev:api` — run the API server on `http://localhost:5000`
- `pnpm run typecheck` — type-check all workspace packages
- `pnpm run build` — build all workspace packages
