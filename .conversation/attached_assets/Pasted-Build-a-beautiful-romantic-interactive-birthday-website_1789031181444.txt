Build a beautiful, romantic, interactive birthday website for my girlfriend.

The website should feel like a **personal digital birthday gift**, not a generic template. The overall experience should be cute, elegant, emotional, and memorable.

She loves the color **pink**, so pink should be the main visual theme.

## CORE DESIGN

Style:

* Romantic
* Soft
* Elegant
* Dreamy
* Premium-looking
* Cute but NOT childish
* Mobile-first
* Fully responsive
* Smooth animations and transitions

Use a sophisticated pink palette:

* Soft blush pink
* Pastel pink
* Rose pink
* White/cream
* Deep rose for important text
* Very subtle gold accents

Do NOT make everything neon pink.

The website should feel like she is **opening a carefully made digital birthday present**.

# TECHNICAL REQUIREMENTS

Use:

* React
* Vite
* Tailwind CSS
* Framer Motion or another appropriate animation library
* Lucide icons if useful

The website must:

* work perfectly on mobile
* work on desktop
* load quickly
* have smooth transitions
* have accessible buttons
* avoid excessive animations that hurt performance
* require no backend
* use clean reusable React components

Organize the project clearly.

For example:

/src
/components
/sections
/assets
/data

Create a central configuration/data file where I can easily change:

* girlfriend's name
* birthday messages
* letter
* card messages
* photos if I add them later
* music
* final message

Add small unexpected interactions:
